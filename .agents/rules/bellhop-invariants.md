# Bellhop Workspace Guardrails

- **Respect `max_connections: 1`:** Never launch live stream validation (`validate` phase) or probe `/live/...` stream URLs unless the user confirms their single IPTV tuner slot is idle. Prefer `bellhop run --dry-run` or `bellhop run --skip validate`.
- **Keep CLI Config-Free:** Put all persistent configuration knobs in `config.yaml` (`src/bellhop/config/`) and `config.example.yaml`. Keep `bellhop` (`run` / `serve`) CLI arguments strictly limited to execution mode and phase selection.
- **Preserve Playable URLs in Local State:** Never redact passwords to `***` inside `state/channel_mapping.json` or exported playlist files (`output/`); redact secrets only in `AppConfig.to_dict(redact_secrets=True)` and public web JSON responses (`/api/lineup`).
- **Google Python Style (2-Space Indent, No Tabs):** Format all Python files with 2-space indentation, spaces only (never tabs), 80-char wrapping, and Google-style docstrings via `.venv/bin/ruff format src tests` and `.venv/bin/ruff check src tests`.
- **Strict TypeScript Frontend:** Author all frontend logic in `src/bellhop/web/frontend/*.ts` (2-space indent, `tsconfig.json` strict mode) and compile to `src/bellhop/web/static/*.js` via `.venv/bin/node ./node_modules/typescript/bin/tsc`; store browser UI state in `localStorage["bellhop.settings"]` via `BellhopSettings`.
- **Verify with `mypy`, `ruff`, `tsc` & `pytest`:** Run `.venv/bin/pytest -q` (which enforces `mypy --strict`, `ruff check/format`, tab-free sources, `tsc --noEmit` + compiled asset sync, and Node frontend unit tests) after changes, and ensure tests write exclusively to `tmp_path` (never mutating real `state/`, `cache/`, or `output/`).
